## 鼠标锁定工具（mouse_lock）
- 新建 Win32/C++ 单文件工具 `mouse_lock.cpp`：启动即锁定鼠标移动，Ctrl+O 全局热键切换锁定。
- 技术方案：`WH_MOUSE_LL` 低层钩子拦截 `WM_MOUSEMOVE`/`WM_NCMOUSEMOVE` 返回 1；`ClipCursor` 作为「强力模式」兜底；`RegisterHotKey(MOD_CONTROL,'O')`；隐藏 `HWND_MESSAGE` 窗口承载热键与托盘回调；托盘图标用 GDI 自绘（无需资源文件）。
- 关键点：托盘菜单展开时必须临时解锁（`g_menuOpen`），否则光标被钉住无法点选菜单项。
- 编译脚本：`build.bat`（MSVC，vswhere 自动定位 + /utf-8）、`build_mingw.bat`、`CMakeLists.txt`、`README.md`。
- 已用本机 MinGW-w64 g++ `-std=c++17 -O2 -municode -mwindows -static` 编译通过（219KB），无警告。注意 `MOD_NOREPEAT` 需自行 fallback 定义，mingw 在仅定义 `_WIN32_WINNT` 时不暴露。
- 未实际运行 exe 做冒烟（会立即锁住用户鼠标），仅验证构建。

### 迭代 1：新增 Shift+O 直接锁定
- 需求：解锁后能快速继续锁。实现第二个全局热键 `HOTKEY_ID_LOCK`（`MOD_SHIFT | MOD_NOREPEAT`, 'O'），语义为「无条件锁定」，与 Ctrl+O 的「切换」区分。
- 重构出 `SetLock(bool locked, bool balloon)`，`ToggleLock` 委托给它；托盘菜单新增 `IDM_LOCK`（已锁定时置灰）；气泡/提示文案区分两个键。
- 已知副作用已写入 README 与使用说明：`Shift+O` 是全局热键，输入大写字母 O 时也会触发锁定；如需更换只需改 `RegisterHotKey(g_hwnd, HOTKEY_ID_LOCK, ...)` 一行。
